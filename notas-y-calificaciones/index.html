Libro de Clases y Calificaciones

Cálculo automático de promedios ponderados, rúbricas generadas con IA, corrección agrupada estilo Gradescope (reduce hasta un 70 % el tiempo de corrección), retroalimentación personalizada por estudiante y alertas automáticas de bajo rendimiento.

Datos del curso

Identifique el curso y la asignatura. Estos datos se guardan automáticamente en este dispositivo.

Instrumentos de evaluación

Configure cada instrumento (prueba, tarea, proyecto) y su ponderación. El promedio se recalcula automáticamente al ingresar cada nota. La suma de ponderaciones debe ser 100 %.

Generador de rúbricas con IA

Describa el objetivo de aprendizaje, el tipo de tarea y el nivel del curso. El sistema genera en segundos una rúbrica completa con criterios, niveles de desempeño y descriptores, lista para editar y utilizar en la retroalimentación personalizada.

Rúbrica generada

Los descriptores son editables: haga clic sobre cualquier celda para ajustar el texto antes de guardarla.

✔ Rúbrica guardada. Ya está disponible en la pestaña de Retroalimentación.

Corrección agrupada estilo Gradescope

Pegue las respuestas de todos los estudiantes a una misma pregunta. El sistema agrupa automáticamente las respuestas equivalentes: usted corrige cada grupo una sola vez —con nota y comentario— y se aplica a todos los estudiantes del grupo, reduciendo hasta un 70 % el tiempo de corrección.

Grupos detectados

Asigne nota (1,0–7,0) y comentario a cada grupo. Al aplicar, la calificación se registra para todos los estudiantes del grupo.

✔ Calificaciones aplicadas a todos los estudiantes de cada grupo.

Retroalimentación personalizada por estudiante

Utiliza la rúbrica guardada: seleccione el nivel de desempeño logrado por cada estudiante en cada criterio y el sistema redacta una retroalimentación individual, formal y orientada a la mejora.

Primero genere y guarde una rúbrica en la pestaña Rúbricas con IA.

Alertas automáticas de bajo rendimiento

El sistema revisa el promedio de cada estudiante en el Libro de Clases y genera una alerta cuando cae bajo el umbral definido, sugiriendo el mensaje de aviso a los apoderados.
